# image-area-highlight
이미지를 불러와 원하는 영역을 드래그하면, 해당 영역만 밝게 남고 나머지는 Dim 처리시키는 이미지 편집기

## 테마
기본은 흰색 배경의 라이트 테마이며, 사이드바 상단의 해/달 아이콘 버튼으로 라이트/다크를 전환합니다. 포인트 컬러는 연두색에 가까운 밝은 파스텔 그린입니다. 선택은 브라우저에 저장되고, 페이지가 열리기 전에 적용되어 깜빡임이 없습니다. 색상은 `style.css` 상단의 디자인 토큰(`:root`, `:root[data-theme="light"]`)에서 한 곳에서 바꿀 수 있습니다.

## 사이드바
작업 패널과 단축키 가이드는 하나의 사이드바에 모여 있고, 이미지 영역이 나머지 화면을 모두 사용합니다.
- **위치 전환:** 사이드바 상단의 **사이드바 위치** 토글(좌측/우측)로 위치를 바꿉니다. 사이드바는 바깥쪽 여백 없이 화면 가장자리에 붙어 화면 높이를 가득 채웁니다.
- **전체 접기:** 사이드바 상단의 화살표 버튼으로 사이드바 전체를 얇은 띠로 접고 다시 펼칩니다. 접으면 이미지 영역이 넓어집니다.
- **구역 접기:** `작업 패널`과 `단축키 가이드`는 각각의 버튼으로 따로 펼치고 접을 수 있습니다.
- 위치, 접힘 상태, 각 구역의 펼침 상태는 브라우저에 저장되어 새로고침해도 유지됩니다.
- 화면 너비가 900px 이하이면 사이드바가 이미지 영역 위로 쌓입니다.

## 번호 라벨
`2. 테두리 스타일`의 **번호 라벨** 스위치(기본 OFF)를 켠 상태에서 만든 박스에는 좌측 상단에 번호 마크가 붙습니다. 박스를 만드는 시점의 설정이 박스별로 저장되므로, 스위치를 켜고 끄며 만들면 번호가 있는 박스와 없는 박스를 섞을 수 있습니다. 번호는 번호가 붙은 박스끼리만 생성 순서대로 1, 2, 3...으로 매겨지며, 삭제·실행 취소 시 자동으로 당겨집니다. 다운로드 이미지에도 포함됩니다. 직접 드래그한 박스와 자동 감지로 만든 박스 모두 적용됩니다.

## 테두리 자동 감지
이미지의 사각형 테두리 박스를 **클릭**하면, 해당 박스 영역을 찾아 자동으로 하이라이트 영역으로 추가합니다. (`autodetect.js`)
- 박스 안쪽을 클릭해도, 테두리 선 위를 클릭해도 같은 박스가 잡힙니다.
- 박스가 중첩되어 있으면 클릭 지점에 가장 가까운(가장 안쪽) 박스가 선택됩니다.
- 둥근 모서리, 연한 회색 테두리, 테두리 없이 색으로만 구분되는 패널, JPEG 압축 이미지를 지원합니다. 두꺼운 테두리(최대 12px)는 바깥쪽 끝까지 포함합니다.
- 점선 박스는 PNG 이미지에서 안쪽을 클릭할 때 가장 잘 동작합니다.
- 박스를 찾지 못하면 안내 메시지만 표시됩니다. 드래그하면 기존처럼 직접 영역을 그립니다.
